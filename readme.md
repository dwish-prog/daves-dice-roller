# Dave's Dice Roller

## Description

As part of the _Codecademy Full-Stack Engineer Career Path_ students are asked to build a random message generator using JavaScript. Since I'm a D&D fan I am creating a dice rolling page. At first this will include buttons for each die. Later I will expand to include flexible entry methods including bonuses/penalties and D&D dice notation.

## Features

- Select your die from 3-100 sides.
- Roll to generate a random result.
- [In progress] Combine multiple rolls for use in D&D.
- [In progress] Add roll modifiers for use in D&D.
